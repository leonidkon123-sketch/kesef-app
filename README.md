# 💛 הכסף שלי

תוכנה חינמית לניהול כסף אישי — בעברית, English, Русский. עובדת גם בלי אינטרנט.

**מה יש בה:** הוצאות והכנסות, חובות והלוואות, כרטיסי אשראי (רק 4 ספרות אחרונות) עם חיוב אוטומטי מהבנק, יתרה ומסגרת, תשלומים עתידיים, יעדי חיסכון, "מוח" חכם עם המלצות, נתוני שוק (דלק, דולר, ריבית, מדד), **קריירה ושכר** (58 מקצועות, 32 מסלולי לימוד, שאלון התאמה מקצועית), ושלושה מצבים: פשוט / רגיל / מקצוען.

## 📱 התקנה
- **אנדרואיד (אפליקציה):** בעמוד [Releases](../../releases/latest) → הורד `kesef-app.apk` → פתח → אשר "התקנה ממקור לא מוכר".
- **כל טלפון / מחשב (בלי חנות):** כשהמאגר יהיה ציבורי — https://leonidkon123-sketch.github.io/kesef-app/ → "הוסף למסך הבית" / "התקן אפליקציה". (במאגר פרטי GitHub Pages לא זמין בחשבון חינמי.)

## 🔒 פרטיות

## 🛠 למפתח
- `index.html` — כל התוכנה (קובץ אחד). `sw.js` — עבודה בלי אינטרנט ועדכונים. `market.json` — נתוני שוק שמתעדכנים אוטומטית.
- כל דחיפה ל-`main` בונה אוטומטית: אתר (GitHub Pages) + APK חתום (GitHub Actions → Releases).
- חתימת APK: סודות `ANDROID_KEYSTORE_B64` ו-`ANDROID_KEYSTORE_PASS` (מפתח קבוע — כדי שעדכונים יותקנו מעל הגרסה הקודמת בלי לאבד נתונים).
